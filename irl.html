Arsitektur Sistem (Versi Revisi SIBI AI)

  • Computer Vision Pipeline: Telah diimplementasikan menggunakan @mediapipe/hands. Menangkap frame, merender kanvas overlay, mengekstrak kordinat landmark (21 titik per tangan).
  • Stabilisasi Prediksi (Smoothing): Sistem menggunakan buffer (antrean multi-frame) untuk mencegah perubahan prediksi yang berkedip/terlalu cepat (flickering).
  • Pengenalan Model (Klasifikasi): Saat ini sistem dapat mendeteksi "Tangan Terbuka" dan "Tangan Tertutup" berdasarkan rumus heuristik jarak landmark untuk demonstrasi pipeline. Model Deep Learning berformat `.tflite` atau `tfjs` yang dilatih menggunakan dataset SIBI dapat diinjeksi pada fungsi predictSIBI(landmarks).
  • Integrasi API Kamera: Mendukung pengalihan stream antar Webcam USB eksternal secara dinamis dan aman tanpa *memory leak*.
